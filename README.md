# Nexora

A modern, UI-first landing page for Nexora Global Industries built with Next.js 14 and Tailwind CSS.

## Overview

- Manufacturer & exporter of premium tile adhesives, PU adhesives, epoxy, grout, and waterproofing.
- Stunning UI with glassmorphism, smooth animations, gradient accents, and responsive design.
- Multi-page app: Home, Catalog, About, and Contact pages.
- Ready for deployment on Vercel.

## Tech Stack

- **Next.js 14** (App Router)
- **Tailwind CSS v3** — utility-first styling with custom design tokens
- **TypeScript**
- Deployed on Vercel

## Pages

| Path | Description |
|------|-------------|
| `/` | Home page — hero, why Nexora, solutions, products, about, testimonials, contact |
| `/catalog` | Filterable product catalog with search, table view, spec cards, and comparison |
| `/about` | Company story, mission, values, and CTA |
| `/contact` | Contact form and office details |

## Scripts

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm run start
```

## Deployment

This project can be deployed to Vercel directly by linking the repository and using the default Next.js settings.

## Catalog

A printable product brochure is available at `/catalog`, and a downloadable catalog text file is available at `/nexora-catalog.txt`.
