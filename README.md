# Nexora

A simple landing page for Nexora Global Industries built with Next.js.

## Overview

- Manufacturer & exporter of premium tile adhesives, PU adhesives, epoxy, grout, and waterproofing.
- Showcases the revised product range and company strengths.
- Ready for deployment on Vercel.

## Scripts

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm run start
```

## Deployment

This project can be deployed to Vercel directly by linking the repository and using the default Next.js settings.
